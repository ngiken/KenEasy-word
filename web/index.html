格式转换与排版支持说明

  • 100% 隐私安全：转换全部在浏览器内存中运算完成，没有后端服务器，文件绝不上云。
  • ODT 格式高保真：深度解析 LibreOffice / OpenOffice ODT XML 结构，完整转换标题层级、粗体斜体、文字颜色、背景高亮、列表、表格与图片。
  • FODT / RTF / HTML / MD：全面支持各种特殊文档结构，一键重排为规范的 Microsoft Word 格式。
  • 合并功能：开启“合并为一个 Word”后，可将多份零散材料依序组合，自动插入分页符与统一章节样式。
  • 纯文本导出：选择 .txt 可快速提纯文本，自动清理冗余格式，并保留清晰的表格与清单结构。
  • 完全免安装：随时在手机或电脑浏览器打开即用，支持离线与局域网静态部署。
